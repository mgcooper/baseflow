Qnonlin

PURPOSE

QNONLIN Plot the theoretical discharge predicted by a/b values.

SYNOPSIS

function [Q,dQdt,t,hFig] = Qnonlin(a,b,Q0,t,varargin)

DESCRIPTION 

QNONLIN Plot the theoretical discharge predicted by a/b values.

 [Q,dQdt,t,hFig] = Qnonlin(a,b,Q0,t) plots a theoretical discharge predicted
 by a/b values for Q = (Q0^(1-b)+a*(b-1).*t).^(1/(1-b));

 b = 1 gives the exponential limit Q = Q0*exp(-a*t). For b < 1 the
 reservoir empties in finite time, after which Q is 0.

 Matt Cooper, 04-Nov-2022, https://github.com/mgcooper

 See also: getfunction, QtauString, QtString

0130 function [Q,dQdt] = qsolution(a,b,Q0,t)
0131    %QSOLUTION Flow of -dQ/dt = aQ^b at times t, from Q(0) = Q0, and its rate.
0132 
0133    % the power law has its exponential limit at b = 1, where 1/(1-b) is Inf.
0134    % For b < 1 the base reaches zero when the reservoir empties, and a
0135    % negative base would give a rebound or a complex flow.
0136    if b == 1
0137       Q = Q0.*exp(-a.*t);
0138    else
0139       Q = max(Q0^(1-b)+a*(b-1).*t, 0).^(1/(1-b));
0140    end
0141
