conversions

PURPOSE

CONVERSIONS convert inputvalue of inputvarname to the value of outputvarname

SYNOPSIS

function varargout = conversions(inputvalue,inputvarname,outputvarname,varargin)

DESCRIPTION 

CONVERSIONS convert inputvalue of inputvarname to the value of outputvarname

 Syntax

     varargout = conversions(inputvalue,inputvarname,outputvarname,varargin)

 Description

     outputvalue = conversions(inputvalue,inputvarname,outputvarname)
     converts inputvalue from its value in terms of inputvarname to its
     equivalent value in terms of outputvarname (use tab completion to get a
     list of supported input and output varnames)

     outputvalue = conversions(_,'isflat',false)
     uses the sloped-aquifer solution. Default behavior is true.

 Example

     b = 1.5;
     n = baseflow.conversions(b,'b','n')
        n = 0


 See also baseflow.getstring

0102    %BCONVERSIONS Convert the recession flow power law exponent b to any of
0103    %several other recession flow parameters.
0104    %
0105    %  Inputs:        b,    from dQ(t)=a*Q^b
0106    %            isflat,    true if flat aquifer
0107    %
0108    %  Outputs:   alpha,    from P(Q) ~ t*^-alpha
0109    %              beta,    from Q ~ S^-beta (beta = -d)
0110    %             gamma,    from 1/gamma = 1/alpha + 1/beta
0111    %                 N,    from a = c1*D^N, where c1 is a coefficient
0112    %             Nstar,    from N* = 1/(N+1)
0113    %                 d,    from Q = cS^d, where d = 1/(2-b)
0114    %                 n,    from k(z) = kD(z/D)^n,
0115    %                 k,    from P(Q) ~ Q^-(1+1/k)
0116    %
0117    % k is the gpfit shape parameter: the gpd tail pdf ~ x^-(1+1/k) equals the
0118    % timescale pdf ~ x^-alpha, so k = 1/(alpha-1) = (1-b)/(b-2).
0119 
0120    alpha = 1./(b-1);       % power law exponent alpha
0121    beta  = 1./(b-2);
0122    gamma = 1./(2.*b-3);
0123    d     = 1./(2-b);
0124    k     = (1-b)./(b-2);
0125 
0126    switch isflat
0127       case true
0128          n = (3-2.*b)./(b-2);   % saturated hyd. cond. power function exponent
0129          N = 3-2.*b;            % scale parameter power law exponent N
0130          Nstar = 1./(4-2.*b);
0131 
0132       case false
0133          n = (1-b)./(b-2);
0134          N = 1-b;
0135          Nstar = 1./(2-b);
0136    end
