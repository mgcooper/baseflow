printtrend

PURPOSE

PRINTTREND Print trends computed from columns in table Data to the screen.

SYNOPSIS

function [ddt, err] = printtrend(Data, varargin)

DESCRIPTION 

PRINTTREND Print trends computed from columns in table Data to the screen.

  Syntax

  [ddt,err] = printtrend(Data,varargin)

  ddt is the trend per year. The printed total change is ddt times the
  years from the first to the last row of Data.

 See also: aquifertrend, baseflowtrend

0016    % create a regular time in years, works for both months and years
