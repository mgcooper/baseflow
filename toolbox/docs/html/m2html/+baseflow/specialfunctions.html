specialfunctions

PURPOSE

SPECIALFUNCTIONS Special function ibarary required for recession analysis.

SYNOPSIS

function varargout = specialfunctions(funcname, varargin)

DESCRIPTION 

 SPECIALFUNCTIONS Special function ibarary required for recession analysis.

  fR1 = specialfunctions('fR1', n) and fR2 = specialfunctions('fR2', n)
  return the early-time and late-time constants of Rupp and Selker
  (2005) for the conductivity profile k(z) = kD*(z/D)^n.

 See also: Qnonlin

 Matt Cooper, 04-Nov-2022, https://github.com/mgcooper

0073 function fR1 = getfR1(n)
0074    % early-time constant of Rupp and Selker (2005), eqs 33 and 56, m = 1.
0075    % gamma is their A (eq 28). fR1/(n+1) is their Phi1 (Table 1: 1.108 at
0076    % n = 0), because a1 here uses kD, as their eq 54 does.
0077    BR1     = beta(n+2, 2);
0078    gamma   = 2 * (n+2) .* BR1;
0079    mu      = (4 - 3*gamma - sqrt(gamma.^2 - 2*gamma + 4)) ./ (4 - 2*gamma);
0080    fR1     = (1-mu) .* (n+1) .* (n+2) ./ (2 * (1 - 2*mu));
0081 end

0083 function fR2 = getfR2(n)
0084    % late-time constant of Rupp and Selker (2005). At n = 0 it is the
0085    % Brutsaert and Nieber (1977) constant 4.804 that fitphi uses for BS04.
0086    % fR2/2 is their Phi2 (eq 59; Table 1: 2.402 at n = 0).
0087    BR2 = beta((n+2) ./ (n+3), 1/2);
0088    fR2 = (n+2) .* (BR2.^(n+3) ./ (n+3)) .^ (1./(n+2));
0089 end
